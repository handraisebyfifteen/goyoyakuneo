# リハーサルの指示書（Claude in Chrome 用）

この文書を、そのまま Claude in Chrome に渡してください。

## あなたにお願いしたいこと

「GoYoyaku-chan Neo（ご予約ちゃん Neo）」という、目の不自由なマッサージ師のための予約アプリのデモ動画を、英語で撮ります。撮る前に、台本どおりに操作して、各場面がちゃんと動くかを確かめてください。

本番では、オーナー役の人がマイクに向かって英語で話します。あなたはマイクを使えないので、**画面の文字入力欄に同じ英語の文を打ち込んで**ください。アプリは文字で話しかけても、声と同じように動きます。

最後に、各場面でアプリが返した文と、気になったことを報告してください。報告は日本語で書いてください（アプリの返事は英語のまま書き写してください）。

## 守ってほしいこと

- この文書に書いてある操作だけをしてください。設定の画面は開かないでください。
- 「Yes／No」を聞かれたら、この文書で指示されたときだけ「Yes」を押してください。指示がなければ「No」を押してください。
- 合言葉（passphrase）を聞かれることはないはずです。もし聞かれたら、入力せずにそこで止めて、報告に書いてください。
- お客さんの名前、電話番号、メールアドレスは、この文書にあるもの以外を入れないでください。
- エラーが出ても、自分で直そうとしないでください。そのまま次の場面に進んで、報告に書いてください。

## 文字で話しかける方法

1. マイクのボタンの下にある**「Type instead, conversation log」**を開く。
2. 「You can also type here」の欄に、英語の文を打ち込む。
3. **「Send」**を押す。
4. アプリの返事が出るまで待つ（5〜15秒ほどかかります）。返事は会話の記録にも残ります。
5. 「Yes」「No」のボタンが出たら、下の指示に従って押す。

## 場面ごとの操作

それぞれ、アプリの返事の文を**そのまま書き写して**ください。かかった秒数もおおよそで書いてください。

📷 の印のところで静止画を撮ってください。返事が出きってから撮ってください。番号（📷 3 など）は報告でも使ってください。

### 場面3：空いている時間
- 打ち込む：`When am I free tomorrow?`
- 確かめること：返事に 14:00（2 PM）が空いていると含まれているか。
- 📷 3：返事が出た画面

### 場面4：予約を入れる
- 打ち込む：`Tanaka, tomorrow from 2 to 3:30.`
- 「Yes／No」の確認文が出るはずです。確認文を書き写してから、**「Yes」**を押してください。
- 📷 4a：「Yes／No」のボタンが出ている画面（押す前）
- 📷 4b：「Yes」を押したあとの返事の画面
- 確かめること：
  - 確認文に、Tanaka、明日の日付、2:00 PM〜3:30 PM が入っているか。
  - 「Yes」のあと、予約ができたと返事があるか。
  - 田中さんのメモ（bad lower back, likes firm pressure）に触れているか（触れていなくても問題ではありません。あったかどうかだけ書いてください）。

### 場面5：お金のこと
- 打ち込む：`What are this month's sales?`
- 確かめること：金額が答えられているか。
- 続けて打ち込む：`Anything unpaid?`
- 確かめること：Sato さんの未払いに触れているか。
- 📷 5：売り上げの返事の画面

### 場面6：お会計
- 打ち込む：`Check Takahashi's cash.`
- カメラ（写真を選ぶ）のボタンが出るはずです。**写真は選ばずに「Cancel」を押してください。** ボタンが出たかどうかだけ書いてください。
- 続けて打ち込む：`Record 5,000 yen from Takahashi, received in cash.`
- 確認文を書き写してから、**「Yes」**を押してください。
- 📷 6a：カメラ（写真を選ぶ）のボタンが出ている画面（「Cancel」を押す前）
- 📷 6b：お金の記録の「Yes／No」が出ている画面（押す前）
- 確かめること：
  - 確認文に「cash」と 5,000 yen が入っているか。
  - 合言葉を聞かれずに記録されたか。

### 場面7：相談
- 打ち込む：`What should a multi-visit ticket cost?`
- 確かめること：お店の料金や来店の数字を使って答えているか。返事の最初の3文を書き写してください（全部でなくてかまいません）。
- 📷 7：相談の返事の画面

## オーナー（あなた）へのメモ

- リハーサルの**前**と**後**に、Replit の Shell で `npx tsx scripts/seed-demo.ts --lang en` を実行してください。リハーサルで入った予約や支払いの記録が消えて、本番用のきれいな状態（英語のお店）に戻ります。`--lang en` を付け忘れると日本語のお店になるので注意してください。
- お金の写真の場面は、Claude in Chrome では写真を選べないので試していません。写真の読み取りは、6枚目の写真で正しく読めることを確認済みです。
- Claude in Chrome は文字で話しかけるので、音声認識（聞き取り）は試せていません。本番の前に、一度ヘッドセットで英語で話しかけて聞き取れるか確かめてください。
